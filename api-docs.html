import requests
import json

url = "https://www.trustlinkgh.online/api/v1/escrows"

payload = json.dumps({
  "amount": 450.00,
  "currency": "GHS",
  "description": "Used iPhone 13 Pro",
  "buyerEmail": "buyer@example.com",
  "buyerPhone": "+233550000000",
  "customReference": "ORDER-1234"
})
headers = {
  'Content-Type': 'application/json',
  'x-api-key': 'tl_live_your_api_key'
}

response = requests.request("POST", url, headers=headers, data=payload)

print(response.text)

Getting Started

To integrate the TrustLink API into your application, you need to make POST requests to our endpoints using your secret API key. All requests should be made over HTTPS and data should be JSON encoded.

Authentication

Pass your API key in the x-api-key header for all requests.

curl -H "x-api-key: tl_live_your_key" https://www.trustlinkgh.online/api/v1/escrows

Webhooks
