Telegram Bot Commands

START & MENU
/start

Launches the bot, presents interactive buttons, and displays available features.

GUIDED WIZARD
/new

Starts an interactive 4-step wizard for Item, Price, Phone, and Fee Split.

FAST CREATE
/create <Price> <Item> <Phone>

Creates a checkout link instantly in one message and alerts the buyer.

BALANCE
/balance

Returns your available wallet balance and funds currently locked in escrow.

ORDERS
/orders

Lists active orders and live payment statuses (Awaiting Payment, Funded, etc.).

DISPATCH
/ship <OrderID>

Marks package as dispatched and notifies buyer via SMS and Telegram.
